# Amazon Kiro for AWS Certified AI Practitioner (AIF-C01)

## 1. What is Amazon Kiro?
> Amazon Kiro is an AI-powered coding assistant / IDE that helps developers build software faster using AI agents.

It converts natural language prompts into:
- Requirements
- Design
- Code
- Tests
- Documentation

Simple meaning:  
➡️ AI helps developers write and manage code.

---

## 2. Why does it matter?
Kiro helps developers:
- Write code faster
- Reduce repetitive work
- Generate documentation
- Debug code
- Improve productivity

Example:
Instead of manually writing 100 lines of boilerplate code, Kiro can generate it.

---

## 3. Agentic AI
Kiro uses **AI agents** that can perform tasks more independently.

Example:
You ask:
`Build a REST API`

Kiro can:
- Create project structure
- Generate code
- Add tests
- Suggest improvements

Simple meaning:  
➡️ AI doesn’t just answer — it performs tasks.

---

## 4. Spec-Driven Development
Kiro follows **specifications (specs)** before coding.

Spec includes:
- Requirements
- Architecture
- Tasks

Example:
Before coding a login system, Kiro defines:
- User requirements
- Security needs
- Implementation steps

Simple meaning:  
➡️ Plan first, code later.

---

## 5. Integration with AWS
Kiro works well with AWS services and is built using AI models through Amazon Bedrock.

It can help build applications using services like:
- EC2
- Lambda
- S3
- DynamoDB

Simple meaning:  
➡️ AI-powered coding for AWS cloud development.

---

## 6. Human Oversight
Even though Kiro is powerful, humans must review AI-generated output.

Why?
Because AI can:
- Make mistakes
- Generate insecure code
- Misunderstand requirements

Simple meaning:  
➡️ Always verify AI output.
